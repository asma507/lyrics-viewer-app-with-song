# 🎵 Lyrics Viewer App with Audio

A simple and user-friendly Flutter mobile application that allows users to play songs and view their lyrics while listening.

## 📱 About the Project

Lyrics Viewer is a mobile application developed using Flutter and Dart. The app provides a simple interface where users can play audio songs and view the corresponding lyrics.

This project was developed to practice Flutter mobile application development, UI design, audio playback, and screen navigation.

## ✨ Features

- 🎵 Play songs
- ⏸️ Pause and resume songs
- 📝 View song lyrics
- ⏭️ Switch between songs
- 🎧 Listen to audio while viewing lyrics
- 📱 Simple and responsive user interface
- 🎨 Clean and easy-to-use design

## 🛠️ Technologies Used

- **Flutter** – Mobile application framework
- **Dart** – Programming language
- **Android Studio / VS Code** – Development environment
