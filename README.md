# 🎵 Lyrics Viewer App with Audio

A simple and user-friendly Flutter mobile application that allows users to play songs and view their lyrics while listening.

## 📱 About the Project

Lyrics Viewer is a mobile application developed using Flutter and Dart. The app provides a simple interface where users can play audio songs and view the corresponding lyrics.

This project was developed to practice Flutter mobile application development, UI design, audio playback, and screen navigation.

## ✨ Features

- 🎵 Play songs
- ⏸️ Pause and resume songs
- 📝 View song lyrics
- ⏭️ Switch between songs
- 🎧 Listen to audio while viewing lyrics
- 📱 Simple and responsive user interface
- 🎨 Clean and easy-to-use design

## 🛠️ Technologies Used

- **Flutter** – Mobile application framework
- **Dart** – Programming language
- **Android Studio / VS Code** – Development environment

🚀 Getting Started

Follow these steps to run the project on your computer.

Prerequisites

Make sure you have installed:

Flutter SDK
Dart SDK
Android Studio or VS Code
Android Emulator or a physical Android device
1. Clone the Repository
git clone <your-repository-url>
2. Open the Project
cd lyrics_viewer
3. Install Dependencies
flutter pub get
4. Check Flutter Setup
flutter doctor

Make sure there are no major configuration issues.

5. Run the Application
flutter run

The application will run on your connected device or Android emulator.

🎵 How It Works
Open the application.
Select a song.
Play the audio.
View the lyrics while the song is playing.
Use the playback controls to pause, resume, or change the song.
