# 🎵 Lyrics Viewer App with Audio

A simple and user-friendly Flutter mobile application that allows users to play songs and view their lyrics while listening.

## 📱 About the Project

Lyrics Viewer is a mobile application developed using Flutter and Dart. The app provides a simple interface where users can play audio songs and view the corresponding lyrics.

This project was developed to practice Flutter mobile application development, UI design, audio playback, and screen navigation.

## ✨ Features

- 🎵 Play songs
- ⏸️ Pause and resume songs
- 📝 View song lyrics
- ⏭️ Switch between songs
- 🎧 Listen to audio while viewing lyrics
- 📱 Simple and responsive user interface
- 🎨 Clean and easy-to-use design

## 🛠️ Technologies Used

- **Flutter** – Mobile application framework
- **Dart** – Programming language
- **Android Studio / VS Code** – Development environment

🚀 Getting Started
Prerequisites

Make sure you have the following installed:

Flutter SDK
Dart SDK
VS Code or Android Studio
Android Emulator or a physical Android device
Clone the Repository
git clone <your-github-repository-url>
Open the Project
cd lyrics_viewer
Install Dependencies
flutter pub get
Run the Application
flutter run

The application will run on your connected device or emulator.

🎵 How the App Works
Open the application.
Select a song.
Play the song.
View the lyrics while listening to the audio.
Use the available controls to pause or resume the song.
📁 Assets

The assets folder contains the resources used by the application, such as audio files and other required assets.

🧪 Testing

To run the tests, use:

flutter test
📦 Build APK

To create an Android APK:

flutter build apk

The generated APK can be found in:

build/app/outputs/flutter-apk/release/
